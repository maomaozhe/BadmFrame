# 自动剪掉死球时间实施计划

目标：实现 BadmFrame 智能剪辑 MVP，自动生成“保留有效回合、剪掉死球时间”的可编辑草稿，并支持导出。

## 当前结论

本计划对应的启发式方案已暂停。真实观看反馈显示剪辑效果很差、输出混乱，不应继续按“调阈值 + 调状态机”的方式推进。

保留本计划作为实验记录。下一轮应先做问题重定义和标注评估，再决定新实现路线。

## 阶段 0：样例与基线

- 准备 2-3 个短测试视频：明显回合、下网捡球、等待发球。
- 定义手工标注格式：`keep` 区间的起止时间。
- 建立评估指标：误删主回合数、剪掉死球比例、分析耗时。
- 不把大视频提交到 git；大样例放本地或外部资产。

产出：

- `web/e2e/fixtures/` 或本地测试素材说明。
- 一份手工标注 JSON 样例。

## 阶段 1：后端特征提取

- [x] 新增 `app/services/analysis.py`。
- [x] 使用 FFmpeg/ffprobe 抽取视频基础信息，并要求真实分析必须有可靠 FFmpeg。
- [x] 低频抽帧并计算 `motion_score`。
- [x] 抽取音频 RMS，得到 `audio_score`。
- [x] 输出按时间窗口排列的 feature JSON。

验收：

- 对短视频输出稳定 feature 序列。
- 单元测试覆盖无音频、短视频、非法路径。

## 阶段 2：回合窗口检测

- [x] 实现自适应阈值：基于分位数确定低/高活动。
- [x] 实现状态机：`idle -> candidate_play -> playing -> candidate_idle -> idle`。
- [x] 实现缓冲、合并短间隔、过滤过短片段。
- [x] 输出 `segments`，包含 `startSec`、`endSec`、`confidence`、`reason`。

验收：

- 对样例视频能保留主要回合。
- 对明显捡球/等待区间生成剪掉区域。
- 参数可配置：保守、平衡、激进。

## 阶段 3：异步任务与 API

- 新增 Celery analysis task。
- 新增 API：
  - `POST /api/v1/videos/{video_id}/analysis`
  - `GET /api/v1/videos/{video_id}/analysis/{task_id}`
  - `POST /api/v1/projects/{project_id}/auto-clips/apply`
- 分析结果先存 JSON 或轻量 DB 字段，避免过早建复杂表。
- 将自动片段转为项目 clips，标记 `source=auto` 或写入 notes。

验收：

- 前端可发起分析并轮询状态。
- 任务失败时返回可读错误。
- 分析完成后能生成项目候选 clips。

## 阶段 4：前端草稿体验

- 在导入/编辑器中加入“自动剪辑”入口。
- 显示分析进度。
- 时间线上显示自动保留段和剪掉段。
- 候选列表支持确认、恢复、删除、微调边界。
- 显示原始时长、保留时长、预计剪掉时长。

验收：

- 用户能看懂系统剪了哪里。
- 用户能恢复误剪片段。
- 自动候选能转入现有导出流程。

## 阶段 5：导出拼接

- [x] 扩展导出服务，支持按多个保留片段拼接输出。
- [x] 保留现有单片段导出能力。
- [x] 导出前校验片段顺序和最短时长。
- [ ] 导出完成后提供可下载静态 URL。

验收：

- 按自动剪辑草稿导出一个连续视频。
- 音频和视频基本同步。
- 取消、失败和重试路径可见。

## 阶段 6：验证与调参

- 用短样例和真实 30-40 分钟视频各跑一轮。
- 记录剪掉比例、误删回合、误保留死球、分析耗时。
- 调整默认参数。
- 更新 `docs/auto-dead-time-editing.md` 中参数和限制。

验收：

- 明显死球时间剪掉 60-80%。
- 主体回合不被整段误删。
- 30-40 分钟固定机位视频能在几分钟内分析完成。

## 优先级

1. 后端 feature + 状态机原型。
2. API + 结果 JSON。
3. 前端草稿展示和用户恢复。
4. 多片段拼接导出。
5. E2E 和真实视频调参。

## 暂不做

- 深度学习模型训练。
- 自动球场线识别。
- 自动计分。
- 多机位同步。
- 直接删除原视频。

## 环境要求

- 后端自动分析和服务端拼接导出必须有可靠 FFmpeg/ffprobe。
- 部署环境应通过 `PATH` 或 `BADMFRAME_FFMPEG_PATH` / `BADMFRAME_FFPROBE_PATH` 指向稳定二进制。
- 不使用临时 `/tmp` 二进制作为正式运行依赖。
