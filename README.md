# BadmFrame

BadmFrame is an early-stage, badminton-focused video editing application. The goal is to help players, coaches, and creators import badminton footage, find useful moments, trim clips, add lightweight annotations, and export shareable review clips.

The project is currently in the context-building phase. Application code and the technology stack have not been selected yet.

## Project Status

- Stage: documentation scaffold and product discovery.
- MVP direction: local-first badminton video clipping and annotation.
- Stack: undecided.
- Contribution style: keep decisions explicit and update project context as the codebase grows.
