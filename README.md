# BadmFrame

BadmFrame 是一个早期阶段的羽毛球视频剪辑应用。它的目标是帮助球员、教练和内容创作者导入羽毛球视频，找到有价值的瞬间，裁剪片段，添加轻量标注，并导出可分享的复盘视频。

项目当前处在上下文建设和产品探索阶段。应用代码和技术栈尚未选定。

## 项目状态

- 阶段：文档脚手架和产品发现。
- MVP 方向：本地优先的羽毛球视频裁剪和标注。
- 技术栈：未决定。
- 协作方式：保持决策显式可追溯，随着代码库成长持续更新项目上下文。
