# 产品上下文

BadmFrame 是面向羽毛球场景的视频剪辑应用。它帮助球员、教练和羽毛球内容创作者，把比赛或训练视频整理成有用片段，而不是被通用剪辑软件的复杂流程拖住。

## 产品定位

- 主要对象：羽毛球视频，常见于手机、GoPro、相机或球友手持拍摄。
- 主要价值：自动找到有效回合，帮助用户快速确认、微调、裁剪并导出羽毛球片段。
- MVP 核心用户：业余爱好者，自己录制打球视频，想剪出精彩或有用片段。
- 优先运行环境：移动端本地运行。iOS/Android 是后续主要产品承载，Web 主要用于测通链路、评估算法和验证工作流。
- 优先自动化能力：识别每个有效回合并输出可确认的候选片段，目标边界误差小于 1s。
- 主要分享场景：本地归档，在应用内浏览和组织自己的打球记录；社区和分享能力可作为后续扩展。

## 核心用户

小王是业余羽毛球爱好者，每周打 2-3 次球，经常用手机或 GoPro 架在场边录制比赛。他想事后回看表现、剪出好球发给球友，或保留失误片段自己复盘。

典型痛点：

- 一场比赛 30-40 分钟，靠拖进度条找某个回合很慢。
- 剪映、iMovie 等通用剪辑器太重，转场、音轨、多轨时间线大多用不上。
- 好球和失误混在长视频里，事后想找时已经忘了位置。
- 同一球局可能有多个角度，但 MVP 先做好单视频流程。

次要用户包括教练、严肃自我复盘球员、内容创作者和帮忙录制的球友。MVP 设计优先满足业余爱好者。

## 核心流程

1. 导入自己录制的训练或比赛视频。
2. 本地模型自动识别有效回合，生成候选片段。
3. 用户逐个确认、删除或微调候选边界。
4. 必要时在关键瞬间打时间点标记，辅助复盘和定位。
5. 导出确认后的片段为常见视频格式，并在本地归档。

## MVP 范围

- 本地视频导入，支持手机、运动相机、相机等常见录制来源。
- 时间线预览和基础拖动浏览。
- 时间点标记，以及通过标记列表跳转。
- 手动选择片段起止时间，可基于标记点快速裁剪。
- 模型识别有效回合，生成需要用户确认的候选片段，目标每个有效回合边界误差小于 1s。
- 片段简单备注。
- 导出选中片段为常见视频格式。
- 保存项目级元数据，使工作可以重新打开和继续编辑。

## Android-first MVP-A

当前 Android MVP-A 先做“可运行骨架”，用于验证“提取回合 -> 逐个快审 -> 转换片段”的产品形态：

- 模型结果先由 mock provider 生成，不代表真实自动识别效果。
- Android 页面展示样例视频占位、候选回合列表、置信度、状态统计和片段草稿。
- 用户可以确认、删除、微调候选回合，并把 accepted/adjusted 候选转换为片段草稿。
- 真视频选择、视频播放、导出和真实模型调用属于后续版本。

这一路线的目标是先稳定移动端交互、状态语义和扩展接口，避免把 UI 绑定到临时 mock 实现。

## MVP 非目标

- 完整专业级非线性剪辑。
- 第一版社区、排行榜、公开发布和社交推荐。
- 云端协作。
- 未经用户确认的一键自动成片。
- AI 自动生成高光片段或自动判断“精彩程度”。
- 高级调色、多机位同步或音频混音。
- 球场空间标注覆盖层。
- 把球轨迹可视化、击球类型识别、自动计分做成第一版主流程。

## 内容组织模型

- 一个项目 = 一次打球记录，包含一段或多段视频素材的概念空间。
- MVP 先支持单视频导入；模型应避免堵死未来多角度关联。
- 标记和片段绑定在时间线上。
- 项目列表按时间倒序显示，用户主要在应用内浏览历史打球记录。
- 本地归档场景下，项目元数据保存在本地，用户可继续编辑和回看片段。

## 成功标准

- 用户能独立完成“导入 -> 自动识别有效回合 -> 快速确认/微调 -> 导出”全流程，不需要看教程。
- 用户仍能用时间点标记和手动裁剪辅助复盘，但这不是后续主路径。
- 每个有效回合的自动候选边界误差目标小于 1s；暂未达到时必须通过人工确认和微调兜底。
- 移动端本地处理是目标形态；Web 端只验证链路和算法评估，不应成为用户完成自动剪辑的长期依赖。
- 用户能在 15 分钟内完成一场 30-40 分钟球局的候选确认、微调和导出。
- 项目可正常保存和重新打开，标记和片段信息不丢失。

## 未决产品问题

- 多角度视频关联是否需要进入 MVP 后续迭代。
- 移动端本地模型的运行方式、耗时、包体和硬件要求。
- 项目默认保存位置、迁移方式和用户可见性。
- 自动候选回合的可用阈值、置信度解释和用户审查成本。
- 社区能力何时进入产品，以及是否只在本地归档稳定后再引入。

## Agent 注意事项

- 产品选择要回到羽毛球复盘、教学和剪辑工作流，而不是通用视频编辑习惯。
- 添加复杂剪辑能力前，先判断它是否真的帮助羽毛球复盘或讲解。
- 自动剪辑是核心能力；新增功能不要削弱“本地识别有效回合并快速导出”的主流程。
