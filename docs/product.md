# 产品上下文

BadmFrame 是面向羽毛球场景的视频剪辑应用。它帮助球员、教练和羽毛球内容创作者，把比赛或训练视频整理成有用片段，而不是被通用剪辑软件的复杂流程拖住。

## 产品定位

- 主要对象：羽毛球视频，常见于手机、GoPro、相机或球友手持拍摄。
- 主要价值：快速找到、标记、裁剪并导出羽毛球片段。
- MVP 核心用户：业余爱好者，自己录制打球视频，想剪出精彩或有用片段。
- 优先标注能力：时间点标记，在时间线上打点定位触球、起跳、得分、失误等关键瞬间。
- 主要分享场景：本地归档，在应用内浏览和组织自己的打球记录，不优先做社交发布。

## 核心用户

小王是业余羽毛球爱好者，每周打 2-3 次球，经常用手机或 GoPro 架在场边录制比赛。他想事后回看表现、剪出好球发给球友，或保留失误片段自己复盘。

典型痛点：

- 一场比赛 30-40 分钟，靠拖进度条找某个回合很慢。
- 剪映、iMovie 等通用剪辑器太重，转场、音轨、多轨时间线大多用不上。
- 好球和失误混在长视频里，事后想找时已经忘了位置。
- 同一球局可能有多个角度，但 MVP 先做好单视频流程。

次要用户包括教练、严肃自我复盘球员、内容创作者和帮忙录制的球友。MVP 设计优先满足业余爱好者。

## 核心流程

1. 导入自己录制的训练或比赛视频。
2. 快速浏览长视频，在关键瞬间打时间点标记。
3. 通过标记列表跳转定位。
4. 围绕标记或手动起止时间裁剪片段。
5. 给片段添加简单备注。
6. 导出片段为常见视频格式，并在本地归档。

## MVP 范围

- 本地视频导入，支持手机、运动相机、相机等常见录制来源。
- 时间线预览和基础拖动浏览。
- 时间点标记，以及通过标记列表跳转。
- 手动选择片段起止时间，可基于标记点快速裁剪。
- 模型识别有效回合，生成需要用户确认的候选片段。
- 片段简单备注。
- 导出选中片段为常见视频格式。
- 保存项目级元数据，使工作可以重新打开和继续编辑。

## MVP 非目标

- 完整专业级非线性剪辑。
- 社交发布平台。
- 云端协作。
- 自动羽毛球轨迹追踪。
- 自动回合识别。
- 高级调色、多机位同步或音频混音。
- 球场空间标注覆盖层。
- AI 自动生成高光片段。

## 内容组织模型

- 一个项目 = 一次打球记录，包含一段或多段视频素材的概念空间。
- MVP 先支持单视频导入；模型应避免堵死未来多角度关联。
- 标记和片段绑定在时间线上。
- 项目列表按时间倒序显示，用户主要在应用内浏览历史打球记录。
- 本地归档场景下，项目元数据保存在本地，用户可继续编辑和回看片段。

## 成功标准

- 用户能独立完成“导入 -> 打标记 -> 裁剪 -> 导出”全流程，不需要看教程。
- 浏览 30 分钟以上长视频并打标记时体验流畅。
- 用户能在 15 分钟内完成一场 30-40 分钟球局的标记和裁剪。
- 项目可正常保存和重新打开，标记和片段信息不丢失。

## 未决产品问题

- 多角度视频关联是否需要进入 MVP 后续迭代。
- 时间点标记的快捷键在移动端和桌面端如何取舍。
- 项目默认保存位置、迁移方式和用户可见性。
- 自动候选回合的可用阈值、置信度解释和用户审查成本。

## Agent 注意事项

- 产品选择要回到羽毛球复盘、教学和剪辑工作流，而不是通用视频编辑习惯。
- 添加复杂剪辑能力前，先判断它是否真的帮助羽毛球复盘或讲解。
- 自动化分析能力默认属于未来范围，除非用户明确要求。
